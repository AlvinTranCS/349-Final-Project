# Typeflow

**Demo:** [https://typeflow-final-project.vercel.app/](https://typeflow-final-project.vercel.app/)

Typeflow is a minimalist, distraction-free typing test application built with React and Tailwind CSS. It allows you to test and improve your typing speed and accuracy in a clean, responsive environment.

## Features
- **Real-time Tracking**: Instant visual feedback on keystroke correctness with a smooth sliding cursor.
- **Dynamic Timer**: Configurable countdown timer (15s, 30s, 60s) that begins on the first keystroke.
- **Game Modes**: Practice with common English words or random gibberish.
- **Results Dashboard**: Calculates Words Per Minute (WPM) and Accuracy percentage at the end of the test.
- **Theme Customization**: Toggle between light and dark modes for a comfortable typing experience.
- **Keyboard Shortcuts**: Use `Tab` to restart and `Esc` to pause/resume the test without using a mouse.
